# PlantUML example layout review

The review covers all **41 source files** in `../plantuml-examples/doc`: **37 diagram-bearing files**, three engine utility listings, and one shared style file. Each diagram was rendered through the extension's actual React Flow browser bundle, with fresh automatic positions, and visually compared with the PNG supplied beside its source. The reference folder is read-only throughout this process. Local includes and procedure source are parsed conservatively; no external PlantUML engine or remote include is executed.

## Reproduce the visual review

```powershell
node scripts/compare-layouts.mjs --examples E:/GitHub/plantuml-examples/doc --phase updated
```

This creates `.cache/layout-comparison/updated/index.html`, seven contact sheets, full-size native screenshots, and a JSON report including parser diagnostics and browser errors. A separately captured `baseline` phase preserves the earlier rendering for review. Use `--resume` only to finish an interrupted phase; it intentionally retains that phase's existing browser bundle and screenshots. A fresh phase should be used after changing renderer code.

The gallery places the supplied PlantUML image on the left and the native editor on the right. Native canvas colors follow the editor theme; this review concerns geometry, grouping, routing, and notation rather than pixel-identical colors or fonts. `NATIVE` in the JSON is a parsing status, not a claim of complete visual parity.
